# EzLand.js
> 🚧 This project is currently under active development.

This is an experimental small library for static landing pages on GitHub Pages.

It uses native Web Components, dynamic imports, and optional Alpine.js integration to deliver reusable, lazy-loadable components with a clean and straightforward development experience.

## Main features
Designed for building modern landing pages without Node.js, bundlers, or build tools.
- ⚡ Zero build setup
- 🚫 No Node.js or npm required
- 🧩 Component-based architecture
- 📦 Lightweight
- 👀 Built-in lazy loading
- ⚙️ Dynamic JavaScript imports
- 🌿 Alpine.js support for reactivity
- 🚀 Optimized for static websites and landing pages
- 💡 Simple, clean, and easy to learn API

Your browser, along with EzLand.js, will assemble the entire page itself!
